# Retrieving memory

[The memory gateway](../layered-memory.md) describes the layers. This FLM corpus holds working memory and governing material together. The Core manifest selects resident reading; recall selects situational guides.

## Find a useful entry

Search relevant `flm/`, `people/`, `projects/`, and external project memory using the notion, synonyms, symptoms, adjacent terms, and contrasts ([my-memory-wide-scan](../concepts/my-memory-wide-scan.md)). Do not infer absence from one phrase or narrow query.

Read the relevant person's or project's root and the current-state entry it identifies. Project AGENTS/CLAUDE instructions apply. Person records own local agreements and signal variants; recall selects the portable signal guidance.

## Follow relations for a reason

| Relation | When and what to read |
| --- | --- |
| `is↑` / `is` | Read the parent for a missing broader frame or condition; continue upward only as needed. |
| `adjacent` / `adjacent-to` | Read a neighbor when it could supply another relevant factor. |
| `is-not` | Read both texts to distinguish meanings and applicability; the relation need not mean logical negation or incompatibility. |
| Reverse link | Search the target slug and inspect the referring text and relation. A mention alone is not a typed relationship. |
| `grounds↓` | Read the transcript for an episode, wording, provenance, or challenge to a claim; read its source if the transcript is insufficient. |

Targets are existing slugs, sometimes aliased. Reverse `is` links find children for deliberate exploration, not automatic recursive loading. Read the needed text before relying on a relation; neither a title nor an association supplies evidence. Assess what each traversal changes in interpretation, grounds, decision, or search.

## Bound the working context

Expand for missing context, not the mere presence of links ([my-memory-upward-gather](../concepts/my-memory-upward-gather.md)). Widen vocabulary or generality when results are sparse; narrow the question or scope when excessive. Ask the operator if the loaded view cannot support narrowing ([my-memory-feast-famine-control](../concepts/my-memory-feast-famine-control.md)). Stop at sufficient context and state material uncertainty.

Themes, topics, and concepts support ordinary reasoning; transcripts and sources recover lost nuance or evidence ([my-memory-grounding-escalation](../concepts/my-memory-grounding-escalation.md)). Distinguish unavailable optional context from missing support required by the conclusion. Do not invent a rule from its title. Reuse present, applicable material under [my-reuse-working-context](../concepts/my-reuse-working-context.md).
