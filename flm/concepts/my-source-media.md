**Source media.** A media source is provenance for a durable local media artifact: image, audio, video, or similar generated/captured asset. It records the final path, UTC creation timestamp, shell/harness, and the prompt or origin note needed to re-ground the artifact. The media file carries the bytes; the source carries why those bytes belong to memory.
