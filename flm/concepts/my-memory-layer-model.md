**Memory layer model.** Knowledge sits in working layers plus a grounding floor: themes -> topics -> concepts -> transcripts -> sources. Themes/topics/concepts generalize and synthesize; transcripts and sources preserve provenance below the reasoning mesh. The split keeps compact handles usable while leaving a path back to the origin material when re-synthesis is needed.
