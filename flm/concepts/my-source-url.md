**Source URL.** A URL source is a pointer-only source for a reachable web location. It carries the address and provenance/gist needed to identify why the URL matters, but it does not copy the page body into memory. If the page content must become grounding rather than a pointer, extract it into a text or file source and mark the capture boundary.
