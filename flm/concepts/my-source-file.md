**Source file.** A file source is provenance for a durable local file artifact that should be grounded as a file rather than copied as text or treated as media: PDFs, documents, datasets, attachments, exports. It records path, origin, capture boundary, and any checksum or version marker that makes the artifact identifiable. If text is extracted from it for reasoning, that extraction becomes a text source or transcript span with its own boundary.
