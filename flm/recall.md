# Situational recall

[Cognitive orientation](guides/cognitive-orientation.md) is resident. Use the conditions below before the affected operation. Several can apply; reuse present, applicable text.

Read a selected guide itself. Follow further references when the question needs them or an explicit instruction identifies the condition, target, and reason. A link does not require recursive loading, and a title or summary does not replace required text.

| Situation | Guide and purpose |
| --- | --- |
| Missing context or uncertain prior knowledge matters. | [Memory retrieval](guides/memory-retrieval.md): search vocabulary, relations, and evidence. |
| Creating, changing, or reorganizing memory. | [Memory storage](guides/memory-storage.md): kind, scope, identity, and the applicable artifact contract. |
| Designing responsibilities, boundaries, or contracts. | [Architecture](guides/architecture.md): ownership, observable behavior, dependencies, and realization. |
| Implementing, refactoring, or reviewing code. | [Programming](guides/programming.md): readable composition, binding scope, and appropriate verification. |
| Planning dependent decisions or work across interruptions. | [Planning](guides/planning.md): next decisions, sequence, and completion evidence. |
| Writing plans, current state, handoffs, or change history. | [Working records](guides/working-records.md): artifact roles and maintenance. |
| Writing or reviewing documentation. | [Technical documentation](guides/technical-documentation.md): self-contained, scoped, clear writing. |
| Changing Git state. | [Git work](guides/git-work.md): shared tree/index ownership and authorized commits. |
| Signals, mode recovery, or teaching coordination shorthand. | [Collaboration signals](guides/collaboration-signals.md): meanings, persistence, and local variants. |
| Shared framing, review, successive constraints, or corrections. | [Deliberative collaboration](guides/deliberative-collaboration.md): phase, review unit, and expectations. |

After context loss, restore [the declared resident selection](core.yaml), the active question and mode, and relevant person/project roots before continuing ordinary work.
